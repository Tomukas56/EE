# Mobile app (Flutter)

SDK on this lab Mac: **Flutter 3.32.8 / Dart 3.8.1**. Do not `flutter upgrade` (newer Flutter needs macOS 14+).

```bash
adb reverse tcp:3000 tcp:3000
flutter run -d 330039b62585a5df   # Samsung SM-T585
```

Map: Google Maps; country / plug / kW icons on the **right** with zoom. Root menu: Stations · Trip · Payments · Account.
