================================================================================
A. FUNKCIJOS (produktas)
================================================================================

1. Krovimo sesija start/stop
   LABORATORIJA VEIKIA: POST /api/sessions, POST /api/sessions/:id/stop, lentelė charging_session.
   Programėlėje stoties detalėse Start/Stop (lab). Energija ir kaina — įvertinimas, ne CPO skaitiklis.
   Vis dar nėra: tikras startas pas operatorių, gyvas kWh, mokėjimas prieš/po sesijos.

2. Mokėjimai ir transakcijos
   Stripe maršrutai yra, bet STRIPE_SECRET_KEY tuščias. Flutter Payment Sheet
   neprijungtas. Istorija dabar rodo lab-estimate iš sesijų, ne PAY001 mock.
   Reikia: PaymentIntent → Apple Pay / Google Pay → webhook, tada PCI SAQ A / PSD2.

3. Maršruto planavimas
   LABORATORIJA VEIKIA: startas/tikslas → atstumas/trukmė; jei kelias ilgesnis nei ~80% automobilio nuotolio, siūloma stotelė.
   Nėra: polilinija žemėlapyje, kelių stotelių grandinė, gyva navigacija.

4. Transporto priemonės profilis
   LABORATORIJA VEIKIA: forma išsaugo make/model/kWh/range/jungtį šiame įrenginyje.
   Nėra: user/vehicle lentelė serveryje, sinchronizacija tarp įrenginių.

5. Autentifikacija production lygiu
   Google Sign-In laidai yra, bet Firebase Android oauth_client tuščias (trūksta
   SHA-1 konsolėje). Yra „Continue on this device“ — tik laboratorijai, store
   build’e turi dingti.

6. Filtrai žemėlapyje / sąraše
   LABORATORIJA VEIKIA: paieška, šalis, jungties tipas, min kW. Operatorius — per paieškos lauką.

7. Gyvas užimtumas (occupancy)
   Visada UNKNOWN. Nėra OCPI / CPO ryšio. Crowd atvykimas — stebėjimas, ne live.

8. Vartotojai duomenų bazėje
   Nėra User lentelės. Crowd reporter_id ir seansas nėra JWT.

9. iOS
   Xcode šiame Mac nepilnas — iPhone build’ų nėra. Apple Pay kol kas neįmanoma
   čia testuoti.

10. OCM duomenų ribotumas
    Lenkija ~380–420 stočių (OCM atsakymas ~524 POI), ne visos šalies tinklas.
    Occupancy ir kaina iš OCM nelaikomi gyvais.

================================================================================
B. SAUGUMAS IR ATITIKTIS (prieš parduotuvę / gyvus pinigus)
    Registras: docs/specs/SECURITY_COMPLIANCE.md
================================================================================

11. Cyber Resilience Act (ES 2024/2847)
    Nėra: rizikos vertinimo, SBOM, CVD kontakto, 24h/72h pranešimų procedūros
    (Art. 14 nuo 2026-09-11 produktams rinkoje), palaikymo laikotarpio, CE / ES
    deklaracijos (nuo 2027-12-11). Negalima dėti į Play/App Store, kol nėra
    pranešimų žaidimo knygos.

12. GDPR / BDAR
    Yra sutartis. Nėra: privatumo politikos, DSR (ištrynimas/prieiga), DPIA,
    tvarkymo veiklos įrašų, DPO proceso.

13. ePrivacy
    Vietos leidimas per OS. Nėra sutikimo žurnalo programėlėje.

14. TLS / HTTPS
    Laboratorijoje HTTP LAN + usesCleartextTraffic. Production privalo būti HTTPS.

15. API be tikros autorizacijos
    Stočių sąrašas atviras. Crowd submit/check-in be user JWT. Owner PIN (2468)
    — tik lab, ne IAM.

16. Seansas SharedPreferences
    Ne Keystore / Keychain. MASVS spraga.

17. Nėra certificate pinning, root/jailbreak politikos, release obfuscation.

18. Google Maps raktas viešame kode
    Reikia apriboti package + SHA-1 / iOS bundle / HTTP referrer. Dabar raktas
    yra kliente ir repozitorijoje.

19. PCI DSS / PSD2
    Nepradėta, kol nėra gyvo Payment Sheet. Kortelių formos nėra (gerai).

20. Pažeidžiamumų peržiūra (MASVS/ASVS)
    Dar neatlikta — planuojama PO laboratorinio funkcinio QA.
